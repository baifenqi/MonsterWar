# MonsterWar

从零开始开发的 ECS 塔防游戏，学习项目。

- 教程：https://cppgamedev.top/courses/ecs-monster-war
- 原项目（仅作参考对照）：https://github.com/WispSnow/MonsterWar （CC0 1.0）
- 本仓库的所有代码均为跟随教程逐步自行实现，开发进度按章节记录在 commit 中。

## 开发计划

按教程章节推进，每章一个或多个提交：

- [ ] 第 1 章：环境安装及测试
- [ ] 第 2-6 章：渲染与基础框架
- [ ] 第 7-10 章：输入信号、事件总线、哈希字符串
- [ ] 第 11 章：引入 ECS 框架
- [ ] 第 12-25 章：关卡载入、实体工厂、战斗、波次等玩法
- [ ] 第 26-29 章：技能、场景、标题/结算画面
- [ ] 自定义扩展内容
